This Privacy Policy applies to the Jahan Bit mobile/desktop application and is prepared for App Store and Google Play compliance. By using the app, you acknowledge this policy.

1. Overview and Scope

Jahan Bit is a local-network management utility for internet subscribers. It connects to your MikroTik RouterOS device on your LAN to list connected devices, manage access (approve/reject, ban/unban), apply speed limits, change Wi‑Fi settings on the router, show package catalogs, and show the subscriber package and name. There is no in-app browser.

Jahan Bit is not an official MikroTik product and does not claim to represent hardware brands.

3. Data Processed or Stored

Depending on use, the following may be stored or processed on your device:

  • Router credentials: RouterOS username/password in platform secure storage (Android Keystore / iOS Keychain) when Remember Me / local session is used.
  • Sign-in: the subscriber username and session token in that secure storage. The username and sign-in password are sent over HTTPS to that province’s worker so the package and name can be shown. A one-time Winbox password is returned once over HTTPS and is then removed from that worker. A permanent sign-in keeps the Winbox password sealed on the same worker and sends it to the phone over HTTPS on each sign-in, only so the app can open the real router. The DeltaSIB API password is never stored on the phone.
  • Connection settings: router host/IP, port, SSL preference, selected province, language, theme.
  • LAN device information: hostname, MAC address, local IP, and ban state for listing and local policy actions you initiate.
  • Local session timestamp: the session stays until you log out. If the app is unused for one year, the sign-in screen is shown again.

Jahan Bit does not create its own cloud user account. The username and sign-in password are sent only to the province HTTPS worker. Router API traffic stays on the local network. The DeltaSIB API password is not on the phone.

4. Data We Do Not Collect (within app scope)

  • GPS / precise location for user tracking
  • Advertising ID / cross-app ad tracking
  • Contacts, SMS, call logs, camera, or microphone
  • Sale of personal data to data brokers

The app does not include advertising SDKs or common ad-analytics SDKs.

5. Local Network Access

Local network access is used only to discover the default gateway and connect to your MikroTik router API. On some antennas the Wi‑Fi page opens in the device’s default browser, not inside the app. The app does not intercept traffic.

6. Package Information

Volume, time, service name, and the subscriber name are read over HTTPS from that province’s accounting service and shown only inside the app. There is no embedded browser and no private-link redirect.

7. Purposes of Processing

  • Authenticate and connect to your router
  • Display and manage connected/banned devices
  • Apply Wi‑Fi and speed settings you request
  • Remember language and theme preferences
  • Show the subscriber package and name

8. Sharing with Third Parties

We do not sell or share your router credentials or LAN device lists with advertisers or advertising analytics providers.

The accounting login is sent only to that province’s HTTPS address. It is not sold and is not sent to advertisers.

9. Security and Transport

  • Credentials are stored in OS secure storage.
  • Management traffic typically stays on your LAN; use trusted networks.
  • Internet requests use HTTPS only. Android blocks cleartext HTTP. iOS allows local networking only so the phone can reach a router on the LAN, and the app does not load public HTTP addresses.
  • Invalid TLS certificates are not accepted.
  • The router connection is a local API socket, not a web page.

No system is 100% secure. You are responsible for protecting router passwords and physical/network access to your device.

10. Retention and Deletion

  • Delete account (Settings → Delete account from this app) removes that username completely from the worker that issued the current sign-in. Every session and every sign-in password for that username on that worker is deleted, including any sealed one-time Winbox password. Herat and Farah share one worker. Nimroz has its own worker, so a Nimroz deletion removes the username only there. The ISP subscriber account in DeltaSIB is not deleted. The app then deletes the data stored on the device.
  • Logout deletes only the current session on that worker. The username and its other sign-in passwords stay until Delete account is used.
  • Uninstalling the app removes on-device app data according to OS behavior.

11. Children

Jahan Bit is a general network utility intended for home/shared network management users. It does not provide child-directed content and does not knowingly collect data from children under 13 (or equivalent age) for advertising. Parents/guardians should supervise minors’ use of the app.

12. Your Rights

Depending on your jurisdiction, you may have rights to access, correct, delete, or restrict processing. Delete account removes that username completely from the worker for the current sign-in and deletes the app data stored on the device. Contact support for further requests.

13. International Transfers

The subscriber username and sign-in password are sent over HTTPS only to that province’s worker. A one-time router password is returned once over HTTPS and is then removed from that worker. A permanent sign-in keeps the router password sealed on the same worker and returns it over HTTPS on each sign-in. Router management traffic stays on the local network. The app does not load ISP subscriber pages.
